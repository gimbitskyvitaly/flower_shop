# Цветочный магазин "Флора"

Веб-сайт для цветочного магазина с каталогом букетов и защищённой паролем админ-панелью.

## Функционал

### Для посетителей:
- 🌸 Просмотр каталога букетов с фотографиями, названиями, ценами и описаниями
- 📍 Контактная информация (адрес, телефон, email, режим работы)

### Для администратора:
- 🔐 Вход по паролю (пароль: `admin123`)
- ➕ Добавление новых букетов в каталог с загрузкой фотографий
- 🗑️ Удаление букетов из каталога (с автоматическим удалением файлов изображений)
- 📝 Управление каталогом через удобный интерфейс

## Структура проекта

```
/workspace/
├── app.py              # Основной файл приложения Flask
├── flowers.db          # База данных SQLite
├── pyproject.toml      # Конфигурация проекта и зависимости
├── uv.lock             # Заблокированные версии зависимостей
├── templates/
│   ├── index.html      # Главная страница (каталог для клиентов)
│   ├── admin.html      # Админ-панель (управление каталогом)
│   └── login.html      # Страница входа для администратора
├── static/
│   └── uploads/        # Загруженные фотографии букетов
└── README.md           # Этот файл
```

## Установка и запуск

### С помощью uv (рекомендуется):

```bash
cd /workspace
uv sync          # Установить все зависимости автоматически
uv run python app.py   # Запустить сервер
```

Зависимости установятся автоматически при первом запуске!

Сервер запустится на порту 5001: http://localhost:5001

## Страницы

- **Главная** (`/`) - Каталог букетов и контактная информация
- **Вход** (`/login`) - Страница входа для администратора
- **Админ-панель** (`/admin`) - Управление каталогом (требуется авторизация)
- **Выход** (`/logout`) - Выход из админ-панели

## Карточка букета содержит:

- Фотографию (загружается файлом или опционально)
- Название (обязательно)
- Цену (обязательно)
- Описание (опционально)

## Безопасность

- Пароль администратора по умолчанию: `admin123`
- ⚠️ **Важно:** В production замените пароль на переменную окружения!
- Сессии защищены секретным ключом
- Поддерживаемые форматы изображений: PNG, JPG, GIF, WEBP
- Максимальный размер загружаемого файла: 16MB

## Технологии

- Python 3.12+
- uv (менеджер пакетов и проектов)
- Flask (веб-фреймворк)
- Flask-SQLAlchemy (ORM для работы с БД)
- SQLite (база данных)
- HTML5 + CSS3
- Werkzeug (безопасная загрузка файлов)

## Управление зависимостями

Все зависимости управляются через `pyproject.toml` и `uv`:

- Добавить новую зависимость: `uv add <package-name>`
- Удалить зависимость: `uv remove <package-name>`
- Синхронизировать зависимости: `uv sync`

## Примеры использования

### Добавление букета через админ-панель:

1. Перейдите на `/admin`
2. Введите пароль: `admin123`
3. Заполните форму:
   - Название букета (обязательно)
   - Цена (обязательно)
   - Описание (необязательно)
   - Загрузите фотографию (необязательно)
4. Нажмите "Добавить букет"

### Удаление букета:

1. В админ-панели найдите букет в таблице
2. Нажмите кнопку "Удалить"
3. Подтвердите удаление
