# Цветочный магазин "Флора"

Веб-сайт для цветочного магазина с каталогом букетов и админ-панелью.

## Функционал

### Для посетителей:
- 🌸 Просмотр каталога букетов с фотографиями, названиями, ценами и описаниями
- 📍 Контактная информация (адрес, телефон, email, режим работы)

### Для администратора:
- ➕ Добавление новых букетов в каталог
- 🗑️ Удаление букетов из каталога
- 📝 Редактирование информации о букетах (через удаление и добавление)

## Структура проекта

```
/workspace/
├── app.py              # Основной файл приложения Flask
├── flowers.db          # База данных SQLite
├── templates/
│   ├── index.html      # Главная страница (каталог для клиентов)
│   └── admin.html      # Админ-панель (управление каталогом)
└── static/             # Статические файлы (CSS, JS, изображения)
```

## Запуск

```bash
cd /workspace
python app.py
```

Сервер запустится на порту 5001: http://localhost:5001

## Страницы

- **Главная** (`/`) - Каталог букетов и контактная информация
- **Админ-панель** (`/admin`) - Управление каталогом (добавление/удаление букетов)

## Карточка букета содержит:

- Фотографию (опционально)
- Название
- Цену
- Описание (опционально)

## Технологии

- Python 3
- Flask (веб-фреймворк)
- Flask-SQLAlchemy (ORM для работы с БД)
- SQLite (база данных)
- HTML5 + CSS3
